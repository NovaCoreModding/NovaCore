NovaCore - All Created Files

AndroidNative/
  Native Android library project files for building libNovaCore.so.

UnityVR/
  VRMenuToggle.cs - left controller primary/X button opens the menu and keeps it 5 inches in front of the player's head.

Important:
- The AndroidNative project and UnityVR script are separate pieces for different project types.
- VRMenuToggle.cs requires a Unity project with UnityEngine/XR references.
- The native Android project does not automatically inject into or modify another application.
